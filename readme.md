\# Curso - IA



Repositorio donde desarrollo distintos proyectos para aprender Inteligencia Artificial con Python.



\## Tecnologías



\- Python

\- Gemini API

\- Google GenAI SDK



\## Instalación



Crear un entorno virtual:



python -m venv .venv



Activarlo:



.venv\\Scripts\\activate



Instalar dependencias:



pip install -r requirements.txt
